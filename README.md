##MossLauncher,

Mosslauncher is a free desktop launcher for Minecraft: Java Edition on Windows.
It is currently in development!

**Moss Launcher isn't an offical Minecraft product. It's not approved or associated with Mojang or Microsoft!**

##Features

- Manage several accounts and game instances
- Install popular mod loades such as Fabric, Forge and Quilt
- Brwose and install mods from Modrinth, including missing dependencies
- Get automated help after a crash trough our built in crash analysis

  ## Why Moss Launcher needs Minecraft API access

  Moss Launcher uses the Microsoft sign-in tp authenticate players and start the game with their own account. Acces to the Minecraft API is needed to confirm that a player owns the game and load their Minecraft Profile-

  ##Privacy & security

  -Your password is entered only on Microsoft's sign-in page, never in the launcher!
  - Sign-in tokens are stored only on your computer, in Windows Credential Manager
  - Sign-in data is not sent to any Moss Server (including Launcher)
  - The Launcher doesn't collect usage data
  - A Minecraft account that owns the Java version is required for full acces to play. Moss Launcher does NOT support cracked or pirated copies.
